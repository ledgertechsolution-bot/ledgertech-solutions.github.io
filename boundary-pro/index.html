Boundary Monitoring Pro Guide

PART I: Paano ilagay sa iyong cellphone Home Screen ang App na ito.

  1. Matapos i-click ang facebook post link, makikita mo ang Boundary Monitoring Pro (BMPro)
  2. Sa taas may tatlong tuldok (⋮) click mo yan.
  3. Hanapin at piliin ang copy link.
  4. Punta ka sa browser na gusto mong gamitin (Ex: Chrome, Edge, Firefox, Brave, etc.) at i-paste ang link.
  5. I-click ng tatlong tuldok (⋮) sa taas at piliin ang ADD TO HOME SCREEN
Guide Recommended:
  1. Mas Magandang pumili ng browser na hindi mo laging ginagamit.
  2. Ito na ang magiging default na tagabukas ng Application na ito.
  3. Iwasan ang mag Browser Clear Data para hindi mabura ang files.

PART II: Paano Gamitin ang Boundary Monitoring Pro

1. Add Driver

  • Pindutin ang + Add Driver na button para maglagay ng bagong driver at i-type ang mga kinakailangang detalye.
  • Awtomatikong madedetect ng sistema ang coding day nito base sa plate number.
  • Para lumipat ng driver, i-tap lamang ang dropdown box sa taas kung saan nakalagay ang pangalan ng kasalukuyang driver o gamitin ang built-in search bar nito

2. Pag-set ng Buwan, Taon, at Boundary Setup

  • Piliin ang tamang Month at ilagay ang Year
  • Ilagay ang kasunduang halaga sa Boundary Set (halimbawa: ₱1,000 o ₱1,200)
  • Kung mayroon silang naiwang balanse o utang mula sa nakaraang buwan, ilagay ito sa Previous Balance para awtomatikong maisama sa komputasyon

3. Pag-save ng Araw-araw na Hulog (Payment Entry)

  • Ilagay ang araw sa Date of payment (halimbawa: 1, 5, atbp)
  • Ilagay ang ibinigay na pera sa Amount Given
  • Pwedeng ilagay ang sakop na petsa (Date Covered) at ang Mode of Payment o Reference Number (MOP/Ref #) o cash
  • I-tap ang I-save button. Agad na kakalkulahin ng app ang Short/Over at ang Running Balance

4. Pag-backup, Pag-export ng CSV, at Pagsara (Lock App)

  • Menu Button (⚙️ Menu ▾): Pindutin ito para makita ang mga opsyon tulad ng Backup Data (JSON), Restore Data, Tier Status/Upgrade, at Lock App kung gusto mong pansamantalang i-lock ang screen para hindi makalikot ng iba
  • Export CSV / PDF: Gamitin ang mga ito para makapag-generate ng kopya ng ulat para sa accounting o kaya ay mai-print/save as PDF at image at mai-send sa driver
