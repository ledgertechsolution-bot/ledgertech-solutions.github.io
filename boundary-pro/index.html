📘 BOUNDARY MONITORING PRO — MANUAL INSTRUCTION

PART I: Pagsasaayos ng Driver at Setup sa Itaas

  • Piliin o Magdagdag ng Driver: I-tap ang Driver Dropdown box sa pinakataas para mamili ng driver mula sa iyong listahan, o gamitin ang built-in Search Bar para mabilis na mahanap ang pangalan.
  • Pindutin ang "+ Add Driver" button para maglagay ng bagong driver at ilagay ang kanyang Pangalan at Plate Number. Awtomatikong dedetektuhin ng sistema ang Coding Day nito base sa huling numero ng plate.
  • Month, Year & Coding Rendering: Piliin ang tamang buwan at taon, o gamitin ang arrow buttons (◀ / ▶) sa tabi ng buwan para mabilis lumipat ng buwan.
  • Coding Rendering (Include / Exclude): Piliin ang Exclude kung nais mong gawing 0 expected boundary ang driver tuwing araw ng kanilang coding.
  • Daily Boundary Set Up: Ilagay rito ang napagkasunduang araw-araw na hulog o boundary ng driver (halimbawa: 1000 o 1200).
  • Updated Running Balance (URB): Ilagay rito ang panimulang balanse o utang ng driver mula sa nakaraang buwan o linggo para awtomatikong maisama sa kabuuang kalkulasyon ng kasalukuyang buwan.

PART II: Pag-save at Pag-encode ng Araw-araw na Hulog

  • Paghuhulog: Ilagay ang araw sa Date of payment (halimbawa: 1, 5, atbp.).
  • Ilagay ang ibinigay na halaga sa Amount Given.
  • Kung sakop ang ilang araw, ilagay ang range sa Date Covered (halimbawa: 10/1 - 10/7) at ilagay ang Reference Number o GCash/Cash sa MOP.
  • Pindutin ang I-save button. Agad na kakalkulahin ng sistema ang Short/Over at ang Running Balance nang awtomatiko.
  • Auto-Advancing Date: Pagka-tap ng save, kusa itong lilipat sa susunod na araw para mas mabilis at tuloy-tuloy ang iyong pag-encode ng mga hulog.

PART III: Menu Options (⚙️ Menu)

I-tap ang ⚙️ Menu ▾ button sa itaas para makita ang mga sumusunod na mahahalagang kasangkapan:

  • 💾 Backup Data: I-save ang kopya ng lahat ng records sa iyong phone bilang JSON file para ligtas sa data loss.
  • 📂 Restore Data: Gamitin ito para ibalik ang mga na-backup mong records sakaling lumipat ka ng cell phone.
  • 📊 Export CSV: I-export ang talaan sa spreadsheet format (Excel/CSV).
    • 📄 Export PDF: Buksan ang pormal at malinis na document layout para ma-save o ma-print bilang opisyal na report.
  • 📘 Manual Instruction: Para mabuksan ang gabay na ito anumang oras sa loob ng app.
  • 👑 Tier Status: Para makita ang kasalukuyang lisensya o mag-upgrade ng TIER (Personal, Entrepreneur, Established, Prime).

PART V: Pag-download ng Larawan (Download Image)

  • Pindutin ang 📥 Download Image button sa tabi ng save button.
  • Awtomatiko itong gagawa ng malinis at pormal na litrato (PNG) ng buong talaan na may puting background na handang-handang i-send direkta sa Messenger o chat ng driver bilang opisyal na update o lingguhang report.
